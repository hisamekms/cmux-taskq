# Architecture decision records

ADRは、将来の実装や運用に大きな影響を与える決定の理由を残す。決定を変更するときは既存ADRを削除・書き換えず、新しいADRを追加する。

## Status

- `proposed`: 検討中
- `accepted`: 採用済み
- `rejected`: 不採用
- `superseded`: 新しいADRに置き換え済み

新しいADRは [template](0000-template.md) をコピーして作る。
